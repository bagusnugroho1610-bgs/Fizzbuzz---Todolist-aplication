## Task 1 - FizzBuzz

Program JavaScript untuk menampilkan angka 1 sampai 100 dengan aturan:

- Kelipatan 3 dan 5: FizzBuzz
- Kelipatan 3: Fizz
- Kelipatan 5: Buzz
- Selain itu: menampilkan angka aslinya.

### cara menjalankan

Pastikan Node.js sudah terinstal.

```bash
node fizzbuzz.js
```

## Task 2 - Todo List Application

Aplikasi Todo List berbasis web yang dibangun menggunakan React dan Bootstrap.

### Technologies

- React.js
- JavaScript
- Vite
- Bootstrap 5
- Bootstrap Icons
- Browser Local Storage

### Fitur

- Create: Add new tasks.
- Read: Display all tasks.
- Update: Edit existing tasks.
- Complete: Mark tasks as completed or pending.
- Delete: Remove tasks.
- Local Storage: Persist task data in the browser.

### Cara menjalankan

1. Clone this repository.
2. Navigate to the Todo App directory.

```bash
cd todo-assessment
```

3. Install dependencies.

```bash
npm install
```

4. Start the development server.

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.
